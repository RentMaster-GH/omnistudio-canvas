\# 🎨 OmniStudio Canvas



An all-in-one AI-powered multimedia studio platform built with \*\*React\*\*, \*\*Fabric.js\*\*, \*\*Node.js\*\*, \*\*FFmpeg\*\*, \*\*Sharp\*\*, and \*\*OpenAI Whisper AI\*\*.



\## 🚀 Features \& Capabilities



1\. \*\*Document \& Image Editing:\*\* Add/delete text, erase, fine-tune (brightness/blur), and overlay text on PDF documents.

2\. \*\*Canvas Animation to MP4:\*\* Record canvas animation sequences frame-by-frame and render them directly into `.mp4` video files.

3\. \*\*Audio + Video Stitching:\*\* Combine video and audio tracks with FFmpeg.

4\. \*\*AI Auto-Subtitles:\*\* Transcribe video/audio using Whisper AI and burn styled subtitles directly onto MP4 videos.

5\. \*\*Save/Load Projects:\*\* Export canvas edits as JSON project files and reload them anytime.
